# 🛡️ Mini-SOC - Walter Solutions

Mini-SOC para detección de ataques. Proyecto personal de **Walter-Solutions**.

## 📌 Descripción

Este proyecto detecta automáticamente:
- Fuerza bruta SSH.
- Escaneo de puertos.
- Acceso a archivos sensibles.

## 🛠️ Componentes

- `generador_logs.py`: Genera logs simulados.
- `analizador_logs.py`: Analiza logs y genera alertas.
- `reglas.json`: Reglas de detección.
- `dashboard.html`: Visualización de alertas.
